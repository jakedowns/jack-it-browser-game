LOADING

Debug / operator overrides

Simulation / controls

Truck-local is the default machine layout: W/S throttle the traction motor, A/D turn the tiller. Switch to camera-oriented if you prefer screen-relative steering.

DRIVE SCHEME
Truck-local maps W/S to forward/reverse. Camera-oriented projects the stick onto the isometric ground plane.
FPV PIP
The fork camera normally hides once the load is captured or the forks pass 35%.
